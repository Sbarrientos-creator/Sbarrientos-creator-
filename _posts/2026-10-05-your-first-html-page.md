HTML is the skeleton of every website you visit. In this tutorial you will build
your first page with nothing but a text editor and a browser.

## What you need

- A computer
- A basic text editor (Notepad, TextEdit in plain-text mode, or VS Code, which is free)
- A web browser

## Step 1: Create the file

Open your editor, paste the code below and save it as `index.html`.

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
    <p>My name is Alex and I am learning to code.</p>
    <a href="https://www.wikipedia.org">Visit Wikipedia</a>
  </body>
</html>
```

## Step 2: Open it

Double-click the file. It opens in your browser. Congratulations, you made a web page!

## What each part does

| Tag | Meaning |
|---|---|
| `<html>` | Wraps the whole page |
| `<head>` | Information about the page, such as its title |
| `<body>` | Everything you see on the page |
| `<h1>` | The main heading |
| `<p>` | A paragraph |
| `<a>` | A link |
