✍️ Generador de posts

CodeCapital · Llena el formulario y publica un post en tu sitio en menos de 1 minuto.

1 Elige un punto de partida

Los ejemplos listos son los dos posts iniciales. Úsalos para ver tu sitio llenarse ya.

2 Escribe tu post

Usa la fecha de hoy o una anterior. Las fechas futuras no se publican.

Formato: ## Subtítulo, **negrita**, - lista, [texto](https://enlace.com). Para código, ponlo entre líneas de tres comillas invertidas.

3 Revisa el archivo que se creará

Se genera solo. Siempre debe empezar con _posts/ y terminar en .md.

Abrir en GitHub para publicar →

4 En GitHub

  1. Se abre la pantalla de “nuevo archivo” con el nombre y el contenido ya puestos.
  2. Haz clic en el botón verde Commit changes… y luego en Commit changes.
  3. Espera 1 a 2 minutos y recarga tu sitio con Ctrl + F5.

Plan B (si GitHub no rellena el contenido): copia el nombre y el contenido y pégalos tú en Add file → Create new file.
