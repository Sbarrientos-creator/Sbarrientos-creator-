# CodeCapital

Student-run website teaching coding and financial literacy. Built with Jekyll and GitHub Pages.

## Add a post
Create a file in `_posts/` named `YYYY-MM-DD-title.md` with this header:

    ---
    layout: post
    title: "Your title"
    categories: code      # or: money
    author: Your name
    ---

Review rule: every post goes through a Pull Request and must be approved by a fact-checker and a teacher before merging.
